Estados

Todos los controles de formulario con cada estado forzado a la vista: el hover, el foco, el clic, el deshabilitado, la solo lectura y el error.

Todos usan el mismo juego de estados (utils/field-styles.ts). Al hacer clic, todos se hunden y les crece el halo, como a Button (también los de escribir); con «reducir movimiento», no se hunden. Cambia el tema del sitio (arriba a la derecha) para verlos en claro y en oscuro.
