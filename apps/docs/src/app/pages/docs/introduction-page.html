Introducción

Mimi es una colección de componentes para Angular 22 y Tailwind CSS 4. No se instala como dependencia: la CLI copia el código a tu proyecto y a partir de ahí es tuyo.

¿Qué es Mimi?

Cada componente es un archivo standalone de Angular con clases de Tailwind y variables CSS --mimi-*. Puedes leerlo, cambiarlo o borrarlo sin pedir permiso a nadie.

Los componentes se distribuyen como código fuente, igual que en shadcn/ui: usan un solo prefijo (mimi) y un archivo de tema opcional tipado, al estilo de los presets de PrimeNG. El objetivo principal es que sean muy fáciles de usar.

Por qué Mimi

Actualizaciones que respetan tus cambios

La CLI guarda la versión original de cada componente en .mimi/base/. Los componentes que modificaste nunca se sobrescriben, y los que no tocaste se actualizan solos al volver a ejecutar ng g mimi. Próximamente, mimi update combinará la versión nueva con tus personalizaciones, mostrando solo los conflictos.

Un solo modelo mental

Sin capas intermedias: un prefijo y todo el código en tu proyecto. Lo que ves en la documentación es exactamente lo que entrega la CLI.

Familiar si vienes de PrimeNG o NG-ZORRO

APIs como showSearch y allowClear, modales por servicio y presets tipados. La documentación incluirá una página de migración con las equivalencias.

Formularios listos

Por qué "Mimi"

Mimi viene de "mi, mi": mis componentes, mis herramientas, mis desarrollos. Empezó como lo que yo usaba en mis propios proyectos.

Pero la idea que más me importa es la contraria: que lo que construyas con Mimi sea tuyo. Por eso Mimi no se instala como una caja cerrada: la CLI copia cada componente a tu proyecto y, desde ese momento, el código es tuyo. Puedes cambiarlo como quieras, y Mimi respeta tus cambios cuando hay versiones nuevas.

Mimi nació como "lo mío". Su promesa es que sea tuyo.
