Instalación

Mimi se instala con una CLI que copia los componentes a tu proyecto. Desde ese momento, el código es tuyo.

1. Requisitos

Angular 22 o superior y Tailwind CSS 4. Para un proyecto nuevo:

Si tu proyecto ya existe y todavía no usa Tailwind, sigue la guía de Tailwind CSS para Angular. Mimi lo verifica antes de empezar: si falta algo, se detiene con un mensaje que explica qué hacer y no modifica nada.

Cuándo usar la forma larga

ng g mimi funciona porque ng add registró Mimi en schematicCollections, dentro de angular.json. Si Mimi no está en esa lista (por ejemplo, porque la editaste o porque otra herramienta la reemplazó), la CLI de Angular no encuentra mimi y hace falta la forma larga, que nombra el paquete y funciona siempre:

Si todavía no ejecutaste ng add @mimi-ng/cli, ninguna de las dos funciona: falta la configuración de Mimi (mimi.json), y la CLI te pide ejecutarlo primero.

4. Úsalos

Importa el componente con el alias @/components/ui en tu componente standalone.

mimi.json y .mimi/

mimi.json es la configuración de Mimi: dónde están el CSS global y la carpeta de componentes, y qué versión de cada componente tienes.

.mimi/ guarda la copia original de cada archivo que escribió Mimi (.mimi/base/) y con qué versión (.mimi/manifest.json). Con esas copias Mimi sabe qué cambiaste tú. Guarda la carpeta .mimi/ en git: sin ella, Mimi no puede distinguir tus cambios y trataría todos tus componentes como modificados.

Si modificaste un componente

  • Los componentes que modificaste nunca se sobrescriben: al volver a ejecutar ng g mimi, se omiten con un aviso.
  • Con --overwrite se reemplazan por la versión de Mimi, y pierdes tus cambios.
  • Los que no tocaste se actualizan solos cuando ejecutas ng g mimi con una versión nueva de la CLI, y te dice cuáles («button actualizado de 0.1.0 a 0.2.0»). Si tu Prettier les dio otro formato, no cuentan como modificados.

Versiones recién publicadas

Desde pnpm 11, minimumReleaseAge vale 1440 minutos por defecto: pnpm espera 24 horas antes de instalar una versión recién publicada. Si minimumReleaseAgeStrict no está configurado, pnpm instala de todos modos una versión que no cumple esa espera, para que la instalación no falle. Más detalles en la documentación de pnpm.
