Button

Botón para acciones y enlaces. Es un componente sobre el elemento nativo, button[mimiBtn] o a[mimiBtn]: conserva todo lo que ya hace un botón (formularios, teclado, foco) y le suma estilos, estado de carga y deshabilitado accesible.

Instalación

Uso

Ejemplos

Tonos

tone elige el color: primary, secondary, success, warning, info o danger.

Variantes

variant elige cómo se ve: solid, soft, outline, ghost o link. Sin tone, cada variante usa su tono natural: outline y ghost son neutros (secondary) y las demás usan primary.

Variante × tono

variant="destructive" sigue funcionando, pero en código nuevo usa tone="danger". Lo mismo con variant="secondary" (ahora tone="secondary") y variant="default".

Tamaños

icon es cuadrado: dale un aria-label, porque no tiene texto.

Con ícono

Los íconos que pongas dentro se dimensionan solos a 16px. En la documentación usamos @lucide/angular.

Deshabilitado y cargando

Con loading el botón muestra un spinner, queda deshabilitado y lleva aria-busy. Pulsa «Guardar» para verlo: el ancho no cambia.

Como enlace

Sobre un <a>, disabled pone aria-disabled, lo saca del orden de tabulación y cancela el clic.

Personalizar con class

Tus clases se mezclan con las del componente usando cn(): si chocan, ganan las tuyas.
