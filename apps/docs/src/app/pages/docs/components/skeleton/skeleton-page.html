Skeleton

Bloque que late mientras el contenido carga. Le das el tamaño y la forma del contenido que va a reemplazar con class.

Instalación

Uso

Ejemplos

Tarjeta

Avatar, dos líneas, un párrafo y un botón, como en el diseño.

Formas

Por defecto tiene el radio pequeño, el de las líneas de texto. Para un avatar usa rounded-full, y para un botón rounded-lg con la altura de los controles.

Mientras carga

Pulsa «Recargar»: el skeleton ocupa el lugar del contenido y aria-busy cambia a la vez.

Personalizar con class

Una imagen de portada con el radio de las tarjetas. Tus clases ganan a las del componente; incluso animate-none lo deja quieto.

Accesibilidad

  • Cada mimi-skeleton lleva aria-hidden="true": no tiene nada que anunciar.
  • Pon aria-busy="true" en el contenedor que carga y un texto para lectores de pantalla: <span class="sr-only">Cargando…</span>.
  • Con movimiento reducido (prefers-reduced-motion) el bloque queda quieto.
