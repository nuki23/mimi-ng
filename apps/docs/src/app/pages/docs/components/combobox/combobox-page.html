Combobox

Un campo donde se escribe para filtrar una lista y elegir una opción. Puede crear valores nuevos y buscar en el servidor.

Instalación

Instala también las utilidades de lista (option-list: el filtro, el resaltado y la lista), el chip (el de Tags Input, para el múltiple) y usa @angular/aria y @angular/cdk.

Uso

Ejemplos

Con <mimi-option>

La misma API que Select: opciones y grupos escritos en la plantilla (también dentro de un @for), con clearable para quitar el valor desde el sitio del chevron.

Con ícono y texto secundario

Prueba «mede»: el filtro no distingue tildes ni mayúsculas. «Lima» está deshabilitada.

Múltiple con chips

Enter agrega o quita la opción activa sin cerrar; Backspace con el campo vacío quita el último chip. Al salir, si hay más de uno, se ve el primero y «+N».

Crear un valor nuevo

Búsqueda en el servidor

searchMode="server" deja el filtro a tu servidor: el Combobox muestra las opciones que llegan, sin volver a filtrarlas, y (searchChange) avisa de lo que se escribe. Prueba «sa» (carga) y «Tokio» (sin resultados).

Formularios y estados

Opción propia, class y panelClass

Con formularios: Signal Forms, Reactive y plantilla

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.

Alternativa: [options] para listas generadas por código

Si la lista ya la arma tu código, pásala entera con [options]: opciones {{ '{' }} label, value {{ '}' }} y grupos {{ '{' }} label, options {{ '}' }}, la misma forma que en Select. Si das [options], gana sobre las <mimi-option>.

Textos

Teclado y accesibilidad

  • Escribir abre la lista y activa la primera coincidencia. ↓ y ↑ abren y recorren; Alt+↓ abre y Alt+↑ cierra; Enter elige; Escape cierra y, con la lista cerrada, vacía el campo.
  • El foco se queda en el campo: la opción activa se anuncia con aria-activedescendant. La cantidad de resultados y «sin resultados» se anuncian en una región de estado.
  • Al salir, lo escrito sin elegir se descarta y vuelve el texto de la opción elegida; con el campo vacío, se quita el valor.
  • Con clearable, Supr o Retroceso quitan el valor elegido (escribiendo, borran letras); en el múltiple, Supr con el campo vacío quita todos los chips. La X se ve con el ratón encima, con el foco dentro o con el panel abierto (en pantallas táctiles, siempre que haya valor).
  • Múltiple: la lista es aria-multiselectable; Enter alterna sin cerrar; Backspace con el campo vacío quita el último chip; Escape cerrado solo vacía lo escrito. Cada chip tiene su botón «Quitar …» (el foco vuelve al campo) y el lector anuncia lo que se agrega y se quita. La ayuda de debajo describe al campo.
