Data Table

Una tabla de datos con búsqueda, filtros, orden, paginación, selección, detalle expandible, acciones por fila y columnas fijas. Tú das las filas y las columnas; ella hace el resto.

Instalación

Trae Checkbox, Chip, Dropdown Menu, Input, Pagination y Toggle Group; la CLI agrega lo que necesiten.

Ejemplos

Clientes: todo activo

Ordena con el encabezado, filtra con el embudo (cada valor es un chip), busca, elige filas (la casilla de arriba marca la página) y abre el detalle con la flecha. La primera columna queda fija al desplazar. Las celdas, el detalle, las acciones y las de la selección son plantillas tuyas.

Mínima, cargando y sin datos

Datos en el servidor

Con [total], la tabla no busca, filtra, ordena ni pagina data: escucha query, sort, filters, page y pageSize, pide esa página y se la devuelves en data (con loading mientras tanto).

Textos

La búsqueda, los nombres de las casillas, los vacíos y el rango están en inglés; esta página usa los de español (y los de Pagination).

Teclado y accesibilidad

  • Es una <table> nativa: encabezados con scope="col", y todo lo que se pulsa es un botón que se recorre con Tab (no hay navegación por celdas).
  • La columna ordenada lleva aria-sort; la fila elegida, aria-selected; la flecha de detalle, aria-expanded y aria-controls.
  • Cada casilla se llama «Seleccionar cliente»; la del encabezado, «Seleccionar todas las filas de la página», con estado parcial.
  • El número de filas elegidas, el rango al buscar o filtrar y «Cargando…» se anuncian en una región de estado.
