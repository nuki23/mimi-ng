Switch

Un control de sí o no que aplica un ajuste al instante. Para marcar una opción que se confirma después (por ejemplo, al enviar un formulario), usa el Checkbox.

Instalación

Uso

El texto de adentro es la etiqueta: al hacer clic en él, el control se alterna. Por dentro es un <button type="button"> con role="switch", así que nunca envía el formulario que lo contiene.

Ejemplos

Estados del switch

Apagado, encendido y deshabilitado. Prueba el foco con Tab: se alterna con Espacio o Enter.

Tamaños

sm (32×18 px), md (36×20 px, por defecto) y lg (44×24 px). Para dar el mismo tamaño a todo un formulario, ponlo una vez en su contenedor con mimiSize.

Etiquetas

Sin texto adentro, nombra el control con aria-label o con un <label for> que apunte a su id: los dos se pasan al botón interno.

Signal Forms

Con [formField], sin adaptadores: el formulario pasa el valor, el estado deshabilitado y el de error.

Reactive Forms y ngModel

También funcionan con formControlName y [(ngModel)]. Este ejemplo usa el switch y el checkbox, que se comportan igual con los formularios. Envía el formulario sin marcar la casilla: queda con el borde de error.

Personalizar con class

class va al envoltorio del control y su texto. Aquí, una lista de ajustes con el texto a la izquierda y el switch a la derecha.

Con formularios: Signal Forms, Reactive y plantilla

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.
