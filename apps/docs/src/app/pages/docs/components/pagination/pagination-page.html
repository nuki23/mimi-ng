Pagination

Una píldora compacta para moverse entre páginas: anterior, la página que se puede escribir, el total, siguiente y, si quieres, los registros por página.

Instalación

Trae Button, Input y Select. El selector de registros llega con @defer: si no usas pageSizeOptions, Select (con @angular/aria y el overlay del CDK) no se carga.

Uso

total es el número de registros; las páginas salen de él y de pageSize. La página empieza en 1. (paginate) avisa una vez por cada acción, para pedir los datos.

Ejemplos

Básico

Escribe una página y pulsa Enter. Un número que no existe muestra «Entre 1 y 12»; al salir del campo o con Escape, vuelve a la página actual. ↑ y ↓ pasan de página.

Registros por página

Con pageSizeOptions. Al cambiar el tamaño se sigue viendo el primer registro que estaba visible.

Controlada

La página se cambia desde fuera con [(page)]; solo las acciones en la paginación emiten (paginate).

Con una tabla

En línea, a la derecha, debajo de la tabla, con el rango a la izquierda.

Flotante

variant="floating" pone la sombra; la posición (centrada abajo) va en class. La tabla deja libre el espacio final.

Tamaños

sm (por defecto, con el alto de control pequeño del tema) y md.

Teclado y accesibilidad

  • Es una región de navegación (role="navigation" con nombre). Cada control es una parada de Tab: son pocos y distintos, y el campo necesita sus flechas.
  • En la primera y la última página, ← y → quedan aria-disabled: el foco no se pierde al llegar y Enter o Espacio no hacen nada.
  • El campo se llama «Página, de 12»; el «/ 12» visible no se lee dos veces. Un número inválido se anuncia con el globo de error.
  • Al cambiar de página, un lector de pantalla oye «Página 3 de 12» (los cambios desde fuera no se anuncian).
  • En pantallas de menos de 640px se oculta el selector de registros: queda ← página / total →.
