Avatar

Foto de una persona con iniciales de respaldo: mientras la imagen carga, si falla o si no hay imagen, se ven las iniciales.

Instalación

Uso

La imagen es el <img> nativo con la directiva mimiAvatarImage: alt, srcset o loading="lazy" funcionan como siempre. Por ahora no admite ngSrc (NgOptimizedImage): usa src.

Ejemplos

Tamaños

Con imagen y solo con iniciales, en los tres tamaños del diseño.

Si la imagen falla

Mientras la imagen carga y si no se puede cargar, se ven las iniciales. El estado queda en data-state (idle | loading | loaded | error) por si quieres darle estilos.

Personalizar con class

Un grupo superpuesto: cada avatar con un anillo del color de fondo, y un contador con otro color. Tus clases ganan a las del componente.

Accesibilidad

  • Pon siempre alt con el nombre de la persona en la imagen.
  • Pasa también label al fallback: si la imagen falla, los lectores de pantalla anuncian el nombre en lugar de leer las letras sueltas.
  • Mientras no carga, la imagen queda oculta para los lectores de pantalla, así el nombre no se anuncia dos veces.
