Checkbox

Marca una opción que se confirma después, por ejemplo al enviar un formulario. Para un ajuste que se aplica al instante, usa el Switch.

Instalación

Uso

El texto de adentro es la etiqueta: al hacer clic en él, la casilla se alterna. Por dentro es un <button type="button"> con role="checkbox", así que nunca envía el formulario que lo contiene. Con formularios (Signal Forms, Reactive Forms y ngModel) funciona igual que el Switch: mira los ejemplos de la página del Switch, que usan los dos controles.

Ejemplos

Estados

Sin marcar, marcada, mixta y deshabilitada. Se alterna con Espacio; Enter no hace nada, como pide el patrón de accesibilidad para casillas.

Tamaños

sm, md (por defecto) y lg. Para dar el mismo tamaño a todo un formulario, ponlo una vez en su contenedor con mimiSize.

Seleccionar todo

Con indeterminate, la casilla principal muestra un guion cuando solo algunas están marcadas.

Con formularios: Signal Forms, Reactive y plantilla

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.
