File Upload

Elegir archivos con un clic, el teclado o arrastrando, validarlos y mostrar su lista con el progreso que da la app. Mimi no sube nada: la subida es de la app.

Teclado y accesibilidad

  • La zona es un botón: se usa sin arrastrar, con Enter o Espacio. Su descripción dice qué acepta.
  • Se anuncian los archivos agregados y los rechazados (con el motivo), y cuándo uno termina o falla; no cada cambio de porcentaje (la barra ya lo expone).
  • Al quitar un archivo, el foco pasa al siguiente, al anterior o a la zona. Con movimiento reducido, la zona no se agranda ni el ícono rebota.
