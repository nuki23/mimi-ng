Password

Un campo de contraseña con un botón para mostrarla u ocultarla y, si lo pides, un medidor orientativo con reglas.

Instalación

Instala también Input. Usa el LiveAnnouncer de @angular/cdk para anunciar el nivel.

Uso

El input es tuyo, con mimiInput, su autocomplete y su formulario: mimi-password lo envuelve y le agrega el botón. Mostrar cambia el type del mismo input, así el gestor de contraseñas y el formulario siguen funcionando.

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.

Accesibilidad

  • El botón es una parada de Tab después del campo, con aria-pressed; su nombre es fijo («Mostrar contraseña», como pide la guía APG para un botón de alternar: el estado lo anuncia aria-pressed) y el foco se queda en él.
  • El medidor describe al campo (aria-describedby, sin borrar el tuyo). El nivel se anuncia solo cuando cambia, no en cada tecla.
  • En Edge, el ojo propio del navegador se oculta: hay uno solo.
