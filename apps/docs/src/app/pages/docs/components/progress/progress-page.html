Progress

El avance de una tarea, determinado o indeterminado, en barra o en círculo.

Instalación

Uso

Ejemplos

Barra

El texto y el valor de arriba son tuyos; la barra los toma como nombre con aria-labelledby.

Indeterminada

Sin value, un tramo cruza la barra. Con «reducir movimiento», la barra late en lugar de desplazarse.

Tonos

Círculo

shape="circle" muestra el valor dentro; size="sm" mide 44px. El indeterminado gira (con «reducir movimiento», late).

Personalizar con class

class va al elemento con el rol (la pista o el círculo) y gana. Con max, el valor puede ser cualquier escala (7 de 12).

Accesibilidad

  • role="progressbar" con aria-valuemin, aria-valuemax y, si es determinado, aria-valuenow; el indeterminado lleva aria-busy="true". No recibe el foco.
  • No anuncia los cambios: el lector lee el valor cuando llega a la barra. Si la tarea termina o falla, avísalo tú (por ejemplo, con un Toast). Así una barra que avanza muchas veces por segundo no satura al lector.
  • Con «reducir movimiento», el indeterminado late y el avance no se anima.
