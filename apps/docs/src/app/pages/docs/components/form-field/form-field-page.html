FormField

Agrupa la etiqueta, el control y el mensaje de error. Lee el estado del formulario y muestra el mensaje correcto sin escribir un solo @if.

Instalación

Uso

  • Funciona con Input, Textarea, Switch y Checkbox, y con Signal Forms, Reactive Forms y ngModel.
  • La etiqueta queda enlazada al control: si el control no tiene id, se le asigna uno.
  • Cuando el campo es inválido y ya se tocó o modificó, la etiqueta se pone roja y aparece el mensaje del primer error. El control lo lleva en su aria-describedby.

Ejemplos

Error automático

Escribe un correo inválido o pulsa «Suscribirme» con el campo vacío.

Etiqueta propia

Para una etiqueta con más detalle, proyecta tu propio <label>: si no tiene for, el form-field se lo asigna, y con error también se pone roja.

Formulario de registro

Card, FormField, Input, Textarea, Checkbox y Button juntos. Pulsa «Crear cuenta» para ver todos los errores.

Personalizar con class

Etiqueta a la izquierda con una grilla. El mensaje va en la segunda columna con class en mimi-form-error.

Personalizar los mensajes

El texto se elige en este orden: gana el primer nivel que tenga un mensaje para el error.

  1. mimi-form-error con tu texto, en un campo.
  2. message en el validador (Signal Forms).
  3. provideMimiErrorMessages, para toda la app.
  4. Los predeterminados, en inglés.

1. mimi-form-error en un campo

Tu texto reemplaza al automático, sea cual sea el error. Aquí la validación es propia, con showError: prueba con «ana» o «admin».

2. message en el validador

Con Signal Forms, el message del esquema viaja con el error. El campo «Contraseña» no lo tiene, así que usa el nivel siguiente.

3. provideMimiErrorMessages

Parte de ...MIMI_ERROR_MESSAGES_ES, cambia los que quieras y agrega los de tus validadores: la clave es la del error (usernameTaken). Lo que no definas queda en inglés. Los datos del error usan los nombres de Reactive Forms en los tres sistemas (requiredLength, min, max…). Borra el campo para ver el required cambiado.

4. Los predeterminados

Sin configurar nada, los mensajes están en inglés (la tabla de arriba). Si un error no tiene mensaje en ningún nivel, se usa default.

El mensaje está siempre en el DOM con aria-live="polite": vacío sin error, así los lectores de pantalla lo anuncian cuando aparece. Los colores salen de --mimi-destructive. FormField no tiene variables propias.
