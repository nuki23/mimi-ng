Input Mask

Un campo que da formato mientras escribes —teléfono, fecha, tarjeta— y guarda solo los dígitos.

Instalación

Uso

Es un control propio (como Number Input), no una directiva sobre tu input: así el formulario recibe los dígitos sin la máscara. Con Signal Forms, una máscara incompleta deja el campo inválido sola (error mask); con Reactive Forms y ngModel, agrega un validador (por ejemplo, Validators.minLength(8)).

La validación de la fecha («31/02 no existe») es del ejemplo, no de Mimi: un validador tuyo sobre los dígitos.

Teclado y accesibilidad

  • El teclado es el del campo de texto. Al escribir o borrar en medio, el cursor se queda después del mismo dígito; borrar sobre un literal borra el dígito de al lado.
  • Pegar funciona con o sin literales («55 1234 5678» o «(55) 1234-5678»). Durante la composición de texto (IME) no se reformatea hasta terminar.
  • Ctrl+Z es el del navegador: después de un reformateo puede deshacer solo hasta el último cambio.
  • Di el formato esperado con texto (aria-describedby a una ayuda), no solo con la máscara.
