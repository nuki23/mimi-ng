Input OTP

Un código de un solo uso en casillas, que el sistema puede proponer desde el SMS y que se puede pegar entero.

Instalación

Uso

Hay un solo campo real, transparente, encima de las casillas: el lector lee un campo con el código entero, y pegar, borrar y el autocompletado del SMS (one-time-code) funcionan como en cualquier campo. La verificación y el mensaje son tuyos.

Con formularios: Signal Forms, Reactive y plantilla

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.

Accesibilidad

  • Una sola parada de Tab; el teclado es el del campo. Las casillas son decorativas.
  • Al pegar «246 810» o «246-810», se quitan los espacios y los guiones. Solo dígitos, salvo con alphanumeric.
  • Pon el mensaje en un elemento con role="status" y enlázalo con aria-describedby.
  • Con «reducir movimiento», el cursor no parpadea y el error no sacude la fila.
