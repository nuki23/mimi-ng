Input y Textarea

Campos de texto de una y de varias líneas. Son directivas sobre los elementos nativos, input[mimiInput] y textarea[mimiTextarea]: funcionan con cualquier sistema de formularios y se ponen en rojo solos cuando hay un error.

Formularios

Funcionan con Signal Forms, Reactive Forms y ngModel sin configurar nada. El campo se pone en rojo cuando es inválido y ya se tocó o modificó. Envuélvelo en mimi-form-field y la etiqueta y el mensaje de error salen solos (ver FormField).
