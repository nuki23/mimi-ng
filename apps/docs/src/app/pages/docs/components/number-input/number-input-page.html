Number Input

Un campo numérico con botones − y +, límites y el formato del idioma: moneda, decimales o unidades.

Instalación

Uso

El formato usa Intl.NumberFormat del navegador: sin dependencias. Con el foco se ve el número sin formato; al salir, se lee con los separadores del idioma («1.250,5» en es-ES), se redondea al paso, se acota y se formatea.

El mismo campo con los tres formularios de Angular. El control implementa la interfaz de Angular: no hace falta un adaptador.

Teclado y accesibilidad

  • Patrón «Spinbutton»: role="spinbutton" con aria-valuenow, los límites y aria-valuetext con el número formateado (el lector dice «$1,250.00», no «1250»).
  • ↑ y ↓ suman o restan un paso; Re Pág y Av Pág, diez; Inicio y Fin van a los límites; Enter confirma lo escrito sin salir del campo.
  • − y + son para el puntero (no son paradas de Tab): mantenerlos pulsados repite. En los límites llevan aria-disabled, así el foco nunca se pierde. La rueda del mouse no cambia el valor.
