Context Menu

Menú que aparece con el clic derecho sobre una zona, una lista o una tabla, en el punto del puntero. Usa los mismos ítems que el Dropdown Menu. Las piezas se importan juntas con MimiContextMenuImports.

Instalación

Instala también los ítems compartidos con el Dropdown Menu (en components/ui/menu), pero no el Dropdown Menu. Como él, usa @angular/aria y @angular/cdk: el comando los instala si faltan (aria en la versión exacta de tu cdk) y agrega los estilos del CDK a tu CSS global:

Elegir un ítem (o Escape) cierra el menú y devuelve el foco al elemento que lo tenía antes de abrir. Los tipos de los ítems, como MimiMenuItemTone, también se importan de @/components/ui/context-menu.

Ejemplos

Básico

El del diseño: ítems con íconos y atajos, uno deshabilitado y una acción destructiva. El menú se abre en el punto del clic y, si no cabe, se voltea hacia el otro lado.

Con submenú

Con el foco en la zona, Shift+F10 o la tecla de menú abren el menú junto a ella, y → abre el submenú.

Con checkbox

[(checked)] con signals. Al marcar, el menú se cierra.

Sobre una tabla

Un solo menú para todas las filas: cada tr es un trigger con su archivo en [mimiContextMenuTriggerData], que el contenido recibe como let-file. La fila abierta lleva data-state="open". Las mismas acciones están en el botón de cada fila, para quien no tiene clic derecho.

Desactivado

Con disabled, Mimi no toca el clic derecho y aparece el menú del navegador.

Teclado y táctil

  • Con el foco dentro de un trigger, Shift+F10 o la tecla de menú abren el menú junto al elemento enfocado. Para eso, la zona (o algo dentro de ella) tiene que poder recibir el foco.
  • Dentro del menú, el teclado es el del Dropdown Menu: flechas, Inicio y Fin, una letra, Enter, Espacio, → y ←, Escape. Tab y un clic fuera lo cierran sin mover el foco.
  • Abierto con el puntero, se cierra al hacer scroll, como el menú del sistema; abierto con el teclado, sigue al elemento.
  • En Android, la pulsación larga abre el menú de Mimi. En iPhone y iPad (sin trackpad) no hay menú contextual: el sistema conserva la pulsación larga para seleccionar texto. El menú contextual es un atajo; deja las mismas acciones en un botón visible.
  • Con el ratón, el foco suele estar en la página (no en la zona) al abrir: al cerrar, vuelve ahí.
