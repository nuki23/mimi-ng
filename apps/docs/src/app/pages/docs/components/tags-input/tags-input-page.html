Varias etiquetas en un campo: se escriben, se ven como chips y se quitan con el teclado o el puntero.

Instalación

Instala también el chip (el mismo que usa el Combobox múltiple) y usa el LiveAnnouncer de @angular/cdk.

Uso

Ejemplos

Con límite

Prueba con una etiqueta repetida o llega a 5. La normalización (minúsculas y sin #) es del ejemplo.

Formularios y estados

Separadores y class

Pegar «ana, luis, sol» agrega las tres.

Textos

Teclado y accesibilidad

  • Enter o un separador agregan; Backspace con el campo vacío quita la última; Tab recorre el campo y los botones de quitar («Quitar angular»).
  • Al agregar o quitar, el lector lo anuncia («angular agregada»). El mensaje de debajo (ayuda, error o límite) y el contador describen al campo.
  • Al quitar con el botón, el foco vuelve al campo.
