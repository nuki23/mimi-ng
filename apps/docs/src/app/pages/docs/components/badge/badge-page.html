Badge

Etiqueta corta para estados, categorías o conteos. Es una directiva sobre el <span> nativo: span[mimiBadge].

Variantes

Con ícono

Los íconos que pongas dentro se dimensionan solos a 12px, el tamaño de la letra, y no se deforman aunque el texto sea largo.

Personalizar con class

Un contador: ancho mínimo, texto centrado y números del mismo ancho. Tus clases ganan a las del componente.
