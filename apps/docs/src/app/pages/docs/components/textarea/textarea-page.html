Textarea

Campo de texto de varias líneas. Es una directiva sobre el elemento nativo, textarea[mimiTextarea]: funciona con cualquier sistema de formularios y se pone en rojo solo cuando hay un error. Para una sola línea, usa Input.

Formularios

Funciona con Signal Forms, Reactive Forms y ngModel sin configurar nada. El campo se pone en rojo cuando es inválido y ya se tocó o modificó. Envuélvelo en mimi-form-field y la etiqueta y el mensaje de error salen solos (ver FormField).

Con formularios: Signal Forms, Reactive y plantilla
