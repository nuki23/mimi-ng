Contenedor para agrupar información y acciones relacionadas. Se arma con seis piezas que importas juntas con MimiCardImports.

Uso

Todas las piezas son opcionales, salvo el contenedor:

    • }

Ejemplos

Completa

Encabezado, contenido y pie con acciones, como en el diseño.

Con un formulario

El <form> envuelve el contenido y el pie, así el botón del pie envía el formulario.

Solo contenido

Sin encabezado, el contenido suma espacio arriba para no quedar pegado al borde. Lo mismo pasa con el pie si es la primera pieza.

Personalizar con class

Una tarjeta destacada con el borde y la sombra del color primario, y otra sin sombra sobre fondo atenuado. Tus clases ganan a las del componente.

Título y accesibilidad

mimi-card-title ya es un encabezado para los lectores de pantalla, de nivel 3. Si en tu página le corresponde otro, cámbialo con level: <mimi-card-title [level]="2">.

Si prefieres tu propio encabezado (<h2>, <h3>…), úsalo en lugar de mimi-card-title, con las mismas clases. No lo pongas dentro de mimi-card-title: los lectores de pantalla anunciarían el título dos veces.
