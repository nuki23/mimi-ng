Formularios y estados

Teclado y accesibilidad

  • Área (un slider): ← y → la saturación, ↑ y ↓ el brillo, de a 2 %; se lee «Saturación 80 %, brillo 90 %».
  • Tono: flechas de a 3°, Re Pág y Av Pág de a 30°, Inicio y Fin.
  • Formato: un grupo de radio con flechas. El campo se confirma con Enter o al salir; si no se entiende, queda marcado como inválido.
  • Paleta y recientes: una parada de Tab cada uno y flechas entre las muestras.
  • Arrastrar con el puntero o el dedo lleva el foco al control.
