## Alerta de entorno: `pnpm test` y Node 26

Con Node 26, `pnpm test` falla en 5 pruebas de docs (`theme.service.spec.ts`, `tokens-page.spec.ts`; a veces `not-found-page.spec.ts`) **también en `main` sin cambios** (comprobado con `git stash` el 04/11/2026). Causa: desde Node 25, `localStorage` es un global de Node que, sin `--localstorage-file`, vale `undefined` y tapa al de jsdom («ExperimentalWarning: localStorage is not available because --localstorage-file was not provided»). Con Node 24 (`.node-version`) no pasa. En esta rama las pruebas se corren con `NODE_OPTIONS=--no-experimental-webstorage` (deja Node 26 como Node 24 en este punto): así `pnpm test` queda todo en verde. No se cambió ningún archivo por esto. Para el usuario: correr con Node 24, o decidir si se agrega la opción a los scripts.
