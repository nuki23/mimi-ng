## G3.2 Sortable List — **DETENIDA (A7): el CSS global pasa el aviso del presupuesto**

**Plan breve** (A2): detallar la tarea (`docs/plan/grupo-3/G3.2.md`, decisiones G3.2-a a G3.2-e); `@angular/cdk/drag-drop` para el puntero y el dedo y teclado propio en el asa; plantilla propia; anuncios en la región visible del diseño; tokens de la G3.0; página con dos ejemplos; registro y spec. **Por qué se detuvo.** `pnpm build` avisa: «styles exceeded maximum budget. Budget 160.00 kB was not met by 1.03 kB with a total of 161.03 kB». CSS global **156,60 → 161,03 kB** crudo, **22,49 → 23,15 kB** gzip (aviso 160, error 175; spec 10). Sortable List sumó 4,43 kB, el doble de lo habitual: las variantes arbitrarias del cdk (`[&.cdk-drop-list-dragging>li:not(.cdk-drag-placeholder)]:…`, `[&.cdk-drag-animating]:…`), las sombras compuestas del levantado y las clases de los ejemplos (Badge con tonos, el número). Con Command, Data Table y `table-01` por delante (unos 2–4 kB cada uno), el grupo terminará **cerca de 170 kB** aunque se recorte esta página. Subir el presupuesto lo decide el usuario (spec 10; `CLAUDE.md`, «Bundle»; A7), así que la cadena para aquí. **Opciones para el usuario:** (a) subir el CSS global del sitio, como en el Grupo 2 (de 160/175 a, por ejemplo, 180/195 kB); (b) mantenerlo y que cada componente del grupo recorte CSS (por ejemplo, variantes del cdk escritas en el CSS del componente y no como utilidades); (c) revisar cómo genera Tailwind las clases de todos los componentes en el CSS global del sitio (las páginas son diferidas, pero sus clases no). Recomendación: (a), que es lo que se hizo con el Grupo 2, más una tarea de mantenimiento para (c).
