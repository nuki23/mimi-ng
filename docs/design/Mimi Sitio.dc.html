Introducción

Mimi es una colección de componentes para Angular 22 y Tailwind CSS 4. No se instala como dependencia: la CLI copia el código a tu proyecto y a partir de ahí es tuyo.

¿Qué es Mimi?

Cada componente es un archivo standalone de Angular con clases de Tailwind y variables CSS --mimi-*. Puedes leerlo, cambiarlo o borrarlo sin pedir permiso a nadie.

Mimi usa Lucide en todos sus componentes. Los iconos son SVG de trazo, heredan el color del texto con currentColor y se dibujan sobre una rejilla de 24px.
