# Diseños de Claude Design

Guarda aquí lo que exportes de Claude Design:

- Las vistas del sitio (HTML o capturas).
- La hoja de componentes de la Fase 1 (estilos Default y Vivid).
- `tokens-default.css` y `tokens-vivid.css`: las variables CSS de cada estilo, en claro y oscuro.

Claude Code debe tomar colores, radios y sombras SOLO de estos archivos.
